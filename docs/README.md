# Docs

This directory contains the comprehensive technical documentation and strategic roadmaps for the Oracle project.

Key documents include:
- `PIPELINE.md`: The start-to-finish guide for running the training phases and inference pipeline.
- `UNIVERSAL_NITRO_ROADMAP.md`: The blueprint for evolving the system into a dynamic, multi-domain Neuro-Symbolic Knowledge Engine backed by PostgreSQL.
- `NOVELTY_BACKLOG.md`: Tracks saturated vs. unsaturated research ideas, serving as the active R&D backlog.
- `CODEBASE_GUIDE.md`: Deep-dive into the architectural choices and polyglot stack.
- `ARCHITECTURE_UML.md`: Structural maps and Mermaid sequence diagrams of the system.
