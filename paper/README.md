# Paper

This directory contains the LaTeX source files and associated assets for the PlantCLEF 2026 research paper.

It documents the formal academic contributions of the Oracle system, including the Gated Feature Aggregation (GFAM) network, the Neuro-Symbolic GCN, and the Polyglot Systems Architecture.

*Note: The `.tex` files are intentionally untracked by git to prevent merge conflicts during concurrent drafting, but the directory remains the primary workspace for academic publication.*
