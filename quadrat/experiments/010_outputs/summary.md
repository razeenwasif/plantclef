## Run: fuse_010 (RRF α-sweep, top-3)

**Experiment ID:** 010_outputs (fusion artefact directory only — no training code lives here)
**Date:** April 2026 (post-009 collapse, pre-010-last_blocks supremacy)

### Why this experiment exists

The 008 PhaseA × **frozen** BioCLIP-2.5 (Arjun's 006 prototype) RRF fusion peaked at α=0.70 top-3 → **0.34642** (+0.016 over Arjun's solo 0.33). The natural next move was to swap the frozen-prototype leg for a *fine-tuned* BioCLIP-2.5 leg that gives true probabilities (not cosine-similarity scores) on the same 7806 species. This directory holds that sweep — PhaseA × **010 head-only** BioCLIP-2.5 fine-tune (the precursor to 010 last_blocks).

### Fusion Algorithm (`fuse_phase_a_bioclip.py`)

Late **rank fusion**, scale-free:
1. For each leg matrix, compute per-row ranks (descending; rank 0 = best species for that quadrat).
2. Convert to RRF score: `score = 1 / (k + rank)` with `k = 60`.
3. Weighted combine: `combined = α · rrf(PhaseA) + (1 − α) · rrf(BioCLIP)`.
4. Top-K argsort per row → submission.

Why ranks, not raw probs: PhaseA's `probs_max` is heavy-tailed/peaky (a few species dominate per quadrat), 010's `probs_mean` is broad/smooth — direct prob-mix lets PhaseA's peaks win argmax even at small α (the 008 `outputs/fusion_lb_direct/submission_direct_lb_a0.20_top3.csv` direct prob-mix at α=0.20 only reached **0.36410**, vs. 010-alone 0.38333). RRF removes the scale mismatch.

### Verdict

**Retired.** Adding PhaseA into 010 hurts. Per the team memory: *"the gap (PhaseA 0.305 vs 010 last_blocks 0.38333) is too large. PhaseA's signal on test quadrats is mostly a noisier subset of what fine-tuned BioCLIP captures; injecting any of it via RRF or direct-mix corrupts BioCLIP's clean top-3 ranking. RRF additionally destroys probability-gradient info; direct-mix preserves it but PhaseA's confident-but-wrong tiles win the argmax."*

The PhaseA leg contributes useful signal **only** when paired with the *frozen* (Arjun) BioCLIP leg, where BioCLIP itself is weaker (0.33). Once BioCLIP is properly fine-tuned (010 head-only at 0.34671 fused, 010 last_blocks at 0.38333 alone), PhaseA stops adding value at any α.

### Status / Next Moves

- **Don't submit more α variants from this directory** — sweep already covered the relevant range and the conclusion is robust.
- **The 008 PhaseA dump (`test_probs_phase_a_multiscale.npz`) stays on disk for sanity** but no new fusions to try.
- **All future submissions should anchor on 010 last_blocks alone** (`outputs/submission_010_last_blocks_resubmit.csv`-style runs).
- **Open levers (per `kaggle_baselines.md`):** 010 with `unfreeze_n ∈ {3, 5, 6}`, different epoch counts (3, 6, 8), mosaics / multi-label aug.

### Key Takeaways

1. **RRF beats direct prob-mix** when the two legs have different score scales/distributions — 0.34671 (RRF) vs 0.36410 (direct, on the stronger 010 last_blocks variant). But neither beats the strong leg alone if the gap is too wide.
2. **Fusion ceiling = strong leg's solo score, minus the noise the weak leg injects.** The 008 PhaseA leg adds signal only when the BioCLIP leg is *also* weak; once BioCLIP becomes strong, the same PhaseA leg becomes a regression.
3. **Top-3 is the sweet spot** for grid_4x4 + softmax_mean BioCLIP submissions (010 K-sweep: top-2 = 0.37313, **top-3 = 0.38333**, top-4 = 0.37174 — confirmed for 010-alone, holds for the fusions too).
4. **All four submissions in this directory are leaderboard-tested artefacts** — preserve them for post-hoc analysis but don't rerun against newer 010 variants without first checking whether the strong-leg alone score is now higher than any α (it is, as of 2026-04-27).
