# Models

This directory is the default output destination for trained model artifacts.

It is structured to hold the weights, configuration snapshots, and optimizer states generated by the various training phases (e.g., `warmup_hardened.pth`, `expert_bioclip_512.pth`, `swa_model_final.pth`). 

*Note: In clustered environments, this directory may be a symlink to a high-speed shared network volume to ensure all pods have access to the latest checkpoints.*
