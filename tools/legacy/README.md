# Legacy SAM Tools

This directory contains obsolete Segment Anything Model (SAM) instance extraction logic that was replaced by the high-speed RGB ExG pipeline in April 2026.

## Files
- `sam_data_extractor.py`: Original SAM-based feature extractor for training data.
- `sam_inference_extractor.py`: Original SAM-based instance segmenter for inference.

These files are preserved for historical reference and potential re-integration if fine-grained instance masks are required in future phases.
